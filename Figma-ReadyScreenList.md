# Notes for Design Consistency

- Color System: Use color-coded maintenance types (oil = yellow, tire = gray, battery = blue, etc.)
- Localization: All text must support Arabic translation (RTL layout toggle in Figma).
- Font & Icon System: Use clean typography + Font Awesome icons.
- State Variants: Each screen should include empty + loading + error versions.

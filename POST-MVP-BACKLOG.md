# These are the features to build after real users validate the core loop:

1. **Expense chart / analytics** — most requested feature once data exists
2. **OCR odometer reading** — solves the mileage staleness problem; use Google ML Kit
3. **Calendar sync** — Google/Apple calendar integration via deep links or native APIs
4. **Car sharing** — share a car with family; owner/viewer roles
5. **Export to PDF** — maintenance report for selling a car
6. **WhatsApp Bot** — reply to snooze (requires WhatsApp Business API setup)
7. **Car Manual Database** — fetch recommended intervals by make/model/year via third-party API
8. **Fuel tracking** — log fill-ups, calculate consumption (separate tab or within maintenance)
9. **Predictive maintenance** — AI suggestions based on mileage patterns and service history
10. **RevenueCat / monetization** — premium tier (multi-car, document storage, advanced analytics)
